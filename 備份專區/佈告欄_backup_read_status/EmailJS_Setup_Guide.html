📧 採購週報系統：EmailJS 設定指南

給採購單位的專屬操作任務單

為了讓系統能以您單位的官方信箱（或共用信箱）自動發送「週報上線通知信」，我們需要您協助註冊發信服務。
請您跟著以下 3 個步驟操作，並將最後取得的 「3 組專屬代碼」 複製並提供給 IT 開發人員，我們將會幫您完成後續的系統串接與替換！

1 註冊 EmailJS 帳號

EmailJS 是一個能讓系統直接透過您的信箱（如 Gmail 或 Outlook）發送信件的安全服務。

1. 前往官方網站：https://www.emailjs.com/

2. 點擊右上角的 「Sign Up Free」 免費註冊帳號。

3. 註冊並登入後，您會進入 EmailJS 的控制面板 (Dashboard)。

2 綁定發信信箱 (取得 Service ID)

接下來，請告訴 EmailJS 您想要用哪個信箱來幫大家寄信。

1. 在左側選單點擊 「Email Services」。

2. 點擊 「Add New Service」，選擇您要使用的信箱類型（推薦使用 Gmail 或 Outlook）。

3. 點擊 「Connect Account」，登入採購單位的公用信箱（或您指定的發信信箱）來進行授權。

4. 授權完成後，點擊 「Create Service」。

5. 成功後，您會在畫面上看到一個 Service ID（類似：service_abc123）。

⚠️ 請將這個 Service ID 複製並記錄下來，稍後需交給開發人員。

3 設定信件內容模板 (取得 Template ID)

我們要設定一封預設的信件版型，未來系統會自動把每週的資訊填入這個版型中。

1. 在左側選單點擊 「Email Templates」，然後點擊 「Create New Template」。

2. 您會看到信件的編輯畫面。請 完全照著以下格式 複製貼上，不要修改括號內的英文字：

To Email (收件人欄位)：請填入 {{to_email}}

Subject (信件主旨)：請填入 {{subject}}

Content (信件內容)：請將下方灰色區塊的內容完整複製貼上：

您好，

{{message}}

週報月份：{{month}}

👉 點此前往查看最新週報：
{{link}}

微笑單車採購團隊 敬上

3. 點擊右上角的 「Save」 儲存。

4. 儲存後，在該畫面的右上角會看到一個 Template ID（類似：template_xyz456）。

⚠️ 請將這個 Template ID 複製並記錄下來，稍後需交給開發人員。

4 取得公鑰 (Public Key) 🌟 任務完成！

最後一步，我們要取得您帳號的安全公鑰。

1. 在 EmailJS 左側選單點擊 「Account」。

2. 進入 「API Keys」 分頁。

3. 您會看到一串 Public Key，請將它複製起來。

🎉 請將以下 3 組資料提交給 IT 開發人員：

您辛苦了！請將您剛剛蒐集到的這三個項目，直接用 LINE 或 Email 傳送給開發人員：

  • Service ID (例如: service_68zzgfe)
  • Template ID (例如: template_8rlsz1f)
  • Public Key (例如: 7eTbBIlRmkkEM-uS3)

開發人員收到後，將會為您處理後台所有的程式設定。下次當您在系統發布週報時，就會正式用您剛才綁定的信箱來寄信囉！
