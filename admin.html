ℹ️ 系統說明與專案成果

1發布錯誤沒關係，一鍵撤回與重發

發現公告有錯字或少傳附件？點擊右上角「撤回發布」，週報就會立刻從前台下架，變成草稿狀態。

修正完畢後再次點選「正式發布」，系統會彈出名單，讓您重新勾選要額外通知的人員，不怕漏發更新版本給長官！

2嚴密的安全防護與精準通知

前台防護：只有使用 @youbike.com.tw 信箱的同仁才能登入前台閱讀週報，保護機密不外洩。

後台白名單：後台內建了「系統設定中心」，您可以自由維護常設的通知名單與群組。發布週報時，可以像點餐一樣輕鬆勾選這次要特別通知誰。

3免安裝、點開即用的雲端系統

不用複雜的安裝步驟，只要雙擊檔案就能開啟。所有的週報資料都會自動存入最高級別的 Firebase 雲端資料庫，隨寫隨存，資料安全不遺失。

4乾淨俐落的編輯畫面

為了讓您有最大的打字空間，我們把文字工具列（粗體、顏色等）藏了起來。

只要您 點擊任何一個段落的文字框，工具列就會聰明地出現在「B 段落內容管理」的標題列上方，既不佔空間又好用！

5豐富的專屬業務表格

除了打字，您還可以點擊每個段落右側的「📊 表格」按鈕，快速插入「漲價料件清單」、「修繕紀錄」等採購專屬表格，資料填寫更結構化。

6誰看過週報？一目了然

系統會自動記錄哪些長官或同仁已經點開閱讀過這份週報，您可以在 C 區塊即時追蹤。

您還可以在右側的「回饋與待辦」區塊，為每篇週報記下需要追蹤的事項，打勾就代表完成！

7統一用語，分類更輕鬆

系統內建了標準的「8 大管理分類」與對應的子標題。當您選擇主分類後，點擊旁邊的子標題欄位，系統會自動推薦關鍵字，省去手動打字的麻煩。

您可以隨時在左側的「📚 關鍵字資料庫維護」中，依照現況新增、修改或停用這些分類選項。

8精心設計的閱讀留白

前台佈告欄的文字與外框之間，我們刻意保留了「黃金比例的留白（空白間距）」。

當未來週報資料量變大、包含長篇交期更新時，這些留白能避免版面變成擁擠的「文字牆」，有效降低視覺疲勞，讓重點一目了然！

9信件必讀公告，重點直達主管信箱

當主管很忙沒空點進網站看公告怎麼辦？

發布週報時，只要打勾「附加必讀公告」，系統就會自動把這份週報裡所有標記為 「緊急」 的項目，整理成文字直接貼在信件內容裡！重點訊息不漏接！

10後台專屬的最高防護：管理員白名單

後台不是任何人都能進來的！為了保護採購資料的安全性，系統特別設立了「管理員白名單」。

您可以從「系統設定中心」隨時新增或移除管理員。當有新人報到或同仁交接時，只要在這裡輸入他的 Email，他就能立刻獲得發布與修改週報的最高權限！

11自由新增群組，一鍵勾選不漏發

每次發布都要一個一個勾選太麻煩？

您可以到「系統設定中心」建立專屬群組。發布時，只要點擊群組名稱，系統就會自動為您勾選該群組內的所有人員，大幅節省發布時間！

12已讀追蹤與智慧防干擾

想知道誰還沒看過緊急公告？

後台的「閱讀狀態追蹤儀表板」除了顯示已讀與未讀名單，更新增了「已讀 / 未讀人數」統計標籤！同時，閱讀過的人員再次登入時，系統會啟動防干擾機制，不會再重複彈出新公告提醒視窗。

13發送與更新時間精準顯示

想知道這篇公告是何時發布或更新的嗎？

系統會在每篇公告的標題下方，以精美的時間膠囊顯示「🕒 發布時間」。如果您後續有對內容進行編輯，系統也會智慧地在後方補充顯示「(最後更新時間)」，讓資訊時效性一目了然。

14自動聚焦當月最新公告，保持版面清爽

歷史週報累積越來越多，會不會很難找？

別擔心！系統設計了精緻的「下拉式月份篩選」，網頁開啟時會自動鎖定在「當前最新月份」，讓畫面上只顯示近期的週報。若需查詢歷史資料，隨時可透過下拉選單切換月份，甚至選擇「全部月份」，且系統會聰明地為您預先選取該月份最新的一篇公告！

15管理員測試前台與強制更新

測試前台權限：身為管理員，您預設擁有全站觀看權限。若想模擬一般同仁測試「權限不足」的阻擋畫面，只需在佈告欄前台網址後方加上 ?test_user=1 即可暫時解除特權。

強制更新機制：系統已內建自動版本檢測功能（Version Checker）。未來當發布任何新功能或修正時，系統會在背景自動比對並強制刷新使用者的網頁，解決以往同仁卡在暫存看不到新版的問題。

16機密週報防護機制

在正式發布的勾選視窗最下方，您可以勾選「⚠️ 設為機密週報」。一旦勾選，這份週報就會被上鎖！

只有被您打勾的收件人登入前台時才能看見這篇週報。沒被勾選的人，連用開發者工具都無法竊取資料。同時前台會強制在背景鋪滿登入者的 Email 浮水印，嚴防截圖外流。

17週報點閱績效統計與匯出

防呆與自動彈出：系統登入後會自動彈出一次「點閱績效統計」，方便即時掌握各營運處主要聯絡人的閱讀狀況。若某營運處未設定主要聯絡人，將自動隱藏避免數據失真並顯示黃色警告。

Excel 匯出：可透過「匯出 Excel」按鈕，快速將當月或上月的統計表格下載為 `.xlsx` 檔案，方便後續彙整與報告。

18閱讀完成率追蹤與落實度分析

前台即時追蹤與完讀滿條：同仁在前台閱讀週報時，頁面最頂端會顯示漸層藍色進度條隨滑動即時推進；滑動至頁面最底端即自動認列為 100% 完整閱讀。凡已看滿 100% 的同仁，重新整理或日後再次點開該篇週報時，頂部進度條將直接常駐為 100% 滿條，提供直觀的完讀標示與成就感！

後台名冊與績效看板：後台「已讀狀態追蹤」名冊可即時查看每位人員的「閱讀完成率」百分比徽章；「點閱績效看板」與「匯出 Excel」同步新增各單位的「平均閱讀完成率」，杜絕僅點開即關閉之形式化簽到，精準掌握各廠處資訊落實狀況！

19進階表格排版、跨欄置中與莫蘭迪色盤操作

Excel/Word 貼上自適應：同仁從 Excel 或 Word 複製表格後直接貼入編輯框，系統會自動去除微軟硬編碼寬度與雜亂樣式，秒轉為 100% 自適應標準邊框與排版，手機瀏覽絕不破版。

欄位對齊與一鍵跨欄置中：工具列提供「靠左、置中、靠右」對齊；選取橫向多個儲存格後，點擊「⊞ 跨欄置中」按鈕，即可瞬間完成合併儲存格與文字水平/垂直雙向置中。

32 色莫蘭迪商務色盤：色盤擴充為 4 大系列（灰階、商務重點、莫蘭迪柔和、高光醒目），並支援自訂顏色選擇器，選取後或點擊編輯區任意處皆能靈敏收合。

20採購使用需求問卷系統與滿意度資料匯出

獨立專屬問卷網頁 (survey.html)：系統建置了現代化獨立問卷頁面，忠實涵蓋「基本資訊、查看頻率、內容理解度評分、版面易讀度評分、資訊/功能需求調查、開放式建議」5 大構面，支援獨立網址跨渠道推播宣傳。

後台即時統計看板：管理員於側邊欄點擊「📝 使用需求問卷統計」，即可直觀檢視總回收份數、各題平均得分、最熱門需求排行與各單位填答明細。

一鍵匯出 Excel：提供「匯出問卷 Excel」按鈕，可將所有原始回覆匯出為標準試算表，便於採購團隊製作分析簡報呈報主管。

21週報撤回安全機制與微軟清單排版保護

一鍵撤回立即下架：管理員點擊「撤回發布」時，週報狀態即刻變更為「草稿 (draft)」，前台同仁端會同步瞬間下架隱藏，確保未定稿或需修正的週報絕不對外曝光。

Word / Outlook 貼上排版防護：系統內建智慧濾網與 DOM 淨化機制，自動修復從 Word 貼入之段落與清單標籤，杜絕序號重複（如 1. 📌 1.）或文字落行，保證版面平整清爽。

22區塊深淺雙層節奏、緊湊排版與倉儲架構擴充

深淺交替雙層循環：公告重點項目（緊急與一般事項）自動套用「深 ➔ 淺」色彩循環交替，徹底消除多項目時的視覺混雜，閱讀邊界清晰直觀。

精緻緊湊字距行距與 13pt：行距由 1.4 收斂至 1.28，段落底距縮小至 2px，消除文字疏離感；TinyMCE 編輯器正式加入「13pt」字號選項，並統一全站字色為沉穩的高階灰黑 (#1e293b)。

9 大主題管理架構：後台關鍵字資料庫正式擴充「六、倉儲管理」，原文件與公告類別順延，全面滿足供應鏈各構面之採購作業分類需求。

23企業帳號強制登入與零資料防窺機制

不開放訪客瀏覽：為貫徹機密資訊保護與 100% 精準已讀追蹤，系統已全面移除訪客瀏覽與略過按鈕。同仁進入前台必須使用 @youbike.com.tw 企業 Google 帳號進行身分驗證。

未登入前「零資料」防護：系統採用前端資料庫攔截機制，在通過身分驗證前，前台完全不向資料庫請求任何週報文字與料號交期，DOM 樹中完全空白，杜絕透過 F12 開發者工具竄改元素跳過驗證竊取機密之可能。

本地安全留存（免重複登入）：驗證成功後，同仁的企業身分將安全留存於瀏覽器中，日常重新整理（F5）或再次造訪無需反覆登入，兼顧頂級資安防禦與極致流暢之使用體驗。

24未登入不可穿透高斯模糊與強制鎖定

背景全域不可穿透鎖定：同仁若於無痕視窗或未登入狀態下開啟前台網頁，主頁面即刻啟動高斯模糊 (filter: blur(8px)) 並禁用所有滑鼠點擊與文字選取 (pointer-events: none)。

無縫防呆驗證：同仁無法透過點擊背景或關閉視窗繞過，必須正式完成 Google 企業帳號登入驗證，系統才會解除模糊鎖定並載入週報，徹底解決窗口因未登入閱讀導致後台查無已讀紀錄之困擾。

25底端一鍵完讀漸層打卡按鈕與尊榮完讀金徽章

長條和諧漸層按鈕：週報正文最底端配置高雅商務微漸層按鈕（藍 ➔ 靛 ➔ 青綠），與莫蘭迪風格完美融合不突兀。同仁詳細閱畢後點擊「✅ 確認已閱讀本期週報內容 (點擊打卡)」，系統即刻以 100% 回傳至雲端資料庫並鎖定按鈕避免重複點擊。

頂部尊榮已完讀金徽章：完成閱讀打卡或滑動深度滿 100% 後，Header 姓名處即刻點亮專屬「👑 2026-WXX 已完讀」琥珀金光輝微漸層徽章，賦予窗口同仁高度尊榮成就感與明確視覺回饋，切換週報時即時聯動！

26雲端打卡同步防護、動態 Loading 與後台手動補登功能

非同步雲端確認機制：同仁點擊「確認已閱讀完畢 (打卡)」時，按鈕立即進入「同步打卡中...」旋轉動畫並鎖定防重複連點。系統嚴格等待雲端 Firestore 資料庫寫入成功回傳後，方鎖定本地已讀與點亮尊榮徽章，杜絕斷線虛假標記。

異常安全回滾與重試：若遇網路瞬斷或請求逾時，系統自動捕捉異常並彈出警示，按鈕瞬間回滾為可點擊狀態，保障同仁隨時能順利重新打卡。

後台手動補登介面：後台「C 已讀狀態追蹤」右上角配置「＋ 手動補登已讀」按鈕。若遇特殊跨區反映或離線閱畢，管理員可開啟彈窗直接選取未讀同仁、設定完成度百分比，一鍵將打卡紀錄安全補登至雲端資料庫並即時刷新 KPI 統計！

27週報選擇性隱藏與特定人員觀看權限設定

選擇性隱藏開關：編輯週報時，基本資訊區新增「👁️ 隱藏此週報」選項。勾選後前台同仁即刻無法看見該週報（後台側邊欄標註 [隱藏] 供管理員維護），方便進行機密校對或特定檔期下架，無需刪除文章。

專案核心亮點與技術邏輯

Serverless 無伺服器架構

捨棄傳統需要買主機、架設作業系統的框架。全站採用 HTML5 + JS 開發，搭配 GitHub Actions 實現 CI/CD，每次修改程式碼就會自動發佈至 GitHub Pages。

  • 維護成本為零，無須擔心主機當機
  • 全球 CDN 加速，開啟網頁瞬間完成
  • 架構極輕量，移交與接手門檻低

Firebase 企業級資料雲

後端資料庫選用 Google 的 Firebase Firestore (NoSQL)，具備極高的擴充性。圖文附件則上傳至 Cloud Storage。

  • 資安防護：透過 Security Rules 嚴格阻擋非管理員的惡意竄改。
  • 稽核軌跡：後台具備 Audit Logs (操作紀錄)，誰在什麼時候發布皆有跡可循。
  • 即時同步更新，資料落地安全有保障。

EmailJS 自動化通知引擎

過去寄發週報需要人工一封封複製貼上，現在系統內建聯絡人與群組管理，並直接串接 EmailJS API。

  • 後台點擊「發布」，自動抓取必讀重點。
  • 動態生成 HTML 豐富排版（包含圖片）寄送給同仁。
  • 徹底消除人工發信的人為疏失與時間成本。

全域權限與強制更新

系統具備 Global Whitelist (全域白名單) 權限控管與 Version Checker (強制更新) 機制。

  • 通訊錄名單即為全站觀看權限，無須逐篇設定
  • 管理員可透過 ?test_user=1 模擬前台權限
  • 發布新版時透過比對 version.txt 強制破除瀏覽器暫存

機密週報防護機制

針對特定高敏資料引入了 ACL (存取控制清單) 機制。發布時動態解析收件群組，並在資料庫底層嚴格管制讀取權限。

  • 資料庫閘門：Firebase Security Rules 從底層攔截越權存取。
  • 動態群組展開：發布時將群組解碼為個人 Email 名單供權限比對。
  • 防外流浮水印：前台自動套用登入者 Email 滿版浮水印，強烈心理嚇阻。

前端版面極致最佳化

為迎合使用者對於「高密度資訊、無留白」的嚴格要求，在前端實作了深度的 HTML 過濾與 DOM 重塑引擎。

  • 智慧空行消除：遞迴剝離富文本編輯器產生的幽靈空白與換行。
  • 響應式懸浮微標：「緊急」標籤改為 Hover 觸發，不佔用任何版面空間。
  • 強制版面壓縮：覆寫 Tailwind 與 Quill 預設樣式，實現 0 padding/margin。

週報點閱績效統計與數據匯出

前後台整合的視覺化 KPI 看板，能自動追蹤各營運處的閱讀狀況，並支援 Excel 報表匯出。

  • 自動結算：自動計算主要聯絡人的應讀與已讀數據。
  • 防呆機制：防呆過濾未設定主要聯絡人的單位，避免數據失真。
  • 公開透明：前台登入自動彈出統計看板，促進團隊內部閱讀積極度。

打破傳統「點開即算已讀」的粗糙統計，前台依據真實捲動深度計算閱畢百分比，並兼顧使用者完讀成就感。

  • 完讀滿條常駐：已達 100% 者重開時直接常駐滿條，直觀標示通關狀態。
