系統全貌與 IT 技術規格白皮書 (Solution C · 已同步 50 項迭代里程碑)

採購佈告欄系統架構與全鏈路運作邏輯

本專案採用 前後端解耦之 Serverless（無伺服器）企業架構。前端託管於 GitHub Pages 搭配全球 CDN；後端全面託管於 Google Firebase (Firestore + Storage + Auth)；通知層直連 EmailJS API。全站具備全集團多網域零信任門禁、憑證過期無縫自癒、行動版智慧表格排版、零實體主機維護負擔與全自動化 CI/CD。

系統核心規格速覽
架構型態 Serverless BaaS
資料庫引擎 Firestore NoSQL
部署機制 GitHub Actions CI/CD
資安管控 多網域零信任 + 防刪

1 系統全鏈路資料流向與分層拓撲 (Architecture Layers)

直覺清晰 · 橫跨使用者、安全閥、前後端至雲端整合
Layer 1 👥

終端使用者與安全門禁

區分「一般同仁 (Reader)」與「採購管理員 (Admin)」，強制經過全集團零信任認證牆。

🔐 全集團多網域 OAuth 門禁 支援 @youbike.com.tw / @giantcycling.com / @giant.com.tw，搭配跨網域白名單匹配與憑證無縫自癒重驗。
👁️ Zero-Data 與 ACL 過濾引擎 未登入前徹底清空 DOM 防 F12 窺探；登入後交叉比對機密白名單與隱藏旗標即時隔離。
流向 ➔ 前端介面層 Security First
Layer 2 🌐

前端介面層 (SPA Client)

以純原生 HTML5 / CSS3 / ES6+ 開發，託管於 GitHub Pages CDN 零延遲發布。

前台 (index.html) 吸頂雙欄流、DOM 關鍵字螢光高亮導覽、行動智慧表格與全螢幕檢視、粉紅附件專區、圖片燈箱、字級縮放、列印 PDF 與一鍵打卡。
後台 (admin.html) & 問卷 (survey.html) TinyMCE 1:1 編輯、Ctrl+S 未儲存監控、段落收合、動態首頁、三大設定工作台、已讀分頁催讀與 3D 黏土進度問卷。
流向 ➔ Firebase BaaS Zero Server Load
Layer 3 ☁️

雲端後端 BaaS (Firebase)

提供高可用性、自動彈性擴展之 NoSQL 資料庫與企業級雲端儲存空間。

🛡️ Security Rules 零信任鐵幕 伺服器端不區分大小寫 (?i) 校驗全集團網域，全集合強制 allow delete: if false 禁止物理刪除。
📦 Firestore & Cloud Storage 管理週報(bulletins)、機密隔離(private)、打卡(readReceipts)、問卷(surveys)、名冊詞庫(systemConfig)、稽核(auditLogs)與附件圖床。
流向 ➔ 外部整合服務 Auto Scaling
Layer 4 ⚙️

自動化與 CI/CD 引擎

整合自動推播 API 與 Git 原始碼版本控管，實現代碼即服務的現代工程。

✉️ EmailJS API 自動推播 發布時自動提取「緊急」必讀項目，動態組合富文本 HTML 郵件發送，並支援一鍵複製群組及未讀催讀信箱。
🚀 GitHub Actions CI/CD 代碼推送 GitHub 自動觸發編譯部署；配合 version.txt 實現客戶端強制破除快取。
自動化閉環完成 Zero Human Error

2 業務核心資料流與防呆時序 (Key Process Workflows)

清晰步驟化呈現前後端資料流
A

企業身分鑑別與權限過濾流

  1. 01 Google 登入與會話還原：透過 Firebase Client SDK 觸發 Google Sign-In，由 onAuthStateChanged 自動維護有效憑證。
  2. 02 全集團網域門禁與自癒重驗：前後端同步校驗 @youbike.com.tw / @giantcycling.com / @giant.com.tw，憑證失效自動觸發 trySeamlessReAuth。
  3. 03 跨網域白名單與實名快取：findUserInWhitelist 依信箱、帳號前綴與實名比對 systemConfig/whitelist，精準綁定單位與中文實名。
  4. 04 Zero-Data 與 ACL 隔離：自動過濾已隱藏週報，機密內文由 private/content 雲端規則鎖定，未授權者零資料外洩。
B

週報發布與 Email 自動推播流

  1. 01 後台高效率富文本編撰：TinyMCE 1:1 表格對齊與 Excel/Word 淨化引擎，搭配 Ctrl+S 快捷存檔、響應式未儲存徽章與段落收合。
  2. 02 三合一多裝置沙盒預覽：切換電腦／平板 (768px)／手機 (414px) 視角實景檢視 1:1 排版與行動版智慧表格，預覽資料不落正式庫。
  3. 03 Firestore 原子寫入與稽核：狀態更新為 published，並自動寫入全員防舞弊 Audit Log 記錄發布者中文實名。
  4. 04 EmailJS 推播與單期分享：自動將本週緊急重點與圖片寄送至群組信箱；前台亦支援 ?id= 單期直達連結分享。
C

完讀打卡閉環與點閱績效統計流

  1. 01 全方位輔助閱讀與一鍵打卡：同仁可藉由關鍵字螢光高亮、章節快跳、全螢幕表格放大器、圖片燈箱與字級縮放讀完全文，並於底部或浮動鈕點擊打卡。
  2. 02 Token 自癒與 100% 完讀存根：寫入前自動刷新憑證，readReceipts 記錄精確時間戳記與 confirmed: true（打卡即 100% 完讀真理）。
  3. 03 前端金徽章鎖定：成功打卡後頂端即時亮起「👑 已完讀」琥珀金徽章並常駐 100% 滿條，閱讀完畢亦可無縫前往 3D 黏土問卷回饋。
  4. 04 KPI 動態彙算與一鍵催讀：後台動態對齊主要聯絡人並排除工程處，提供分頁篩選、一鍵複製未讀 Email 催讀與 SheetJS 點閱時間報表導出。

3 專案核心亮點與深度技術架構 (Technical Highlights · 18 大構面)

涵蓋 50 項里程碑 · 滿足企業級維護、體驗與資安標準

Serverless 無伺服器架構

捨棄傳統需要買主機、架設作業系統的框架。全站採用 HTML5 + ES6+ JS 開發，搭配 GitHub Actions 實現 CI/CD，每次修改程式碼即自動發佈至 GitHub Pages。

  • 維護成本為零，無須擔心實體主機硬體當機
  • 全球 CDN 加速，開啟網頁瞬間完成零延遲
  • 架構極輕量，移交與接手門檻低

Firebase 企業級資料雲

後端資料庫選用 Google 的 Firebase Firestore (NoSQL)，具備極高的擴充性。圖文附件則上傳至 Cloud Storage。

  • 資安防護：透過 Security Rules 嚴格阻擋非管理員的惡意竄改。
  • 稽核軌跡：後台具備 Audit Logs (操作紀錄)，誰在什麼時候發布皆有跡可循。
  • 即時同步更新，資料落地安全有保障。

EmailJS 自動化通知引擎

過去寄發週報需要人工一封封複製貼上，現在系統內建聯絡人與群組管理，並直接串接 EmailJS API。

  • 後台點擊「發布」，自動抓取必讀重點。
  • 動態生成 HTML 豐富排版（包含圖片）寄送給同仁。
  • 徹底消除人工發信的人為疏失與時間成本。

全域權限與強制更新

系統具備 Global Whitelist (全域白名單) 權限控管與 Version Checker (強制更新) 機制。

  • 通訊錄名單即為全站觀看權限，支援跨集團網域智慧匹配
  • 管理員可透過 ?test_user=1 模擬前台權限
  • 發布新版時透過比對 version.txt 強制破除瀏覽器暫存

機密週報防護與選擇性隱藏

針對高敏或特定廠區週報引入 ACL 存取控制、雲端機密保險箱 (private/content) 與選擇性隱藏開關。

  • 精準存取過濾：非授權同仁清單完全不顯示，網址直接開啟亦安全鎖定。
  • 選擇性隱藏開關：校對中或特定檔期一鍵隱藏，毋須刪除歷史文檔。
  • 防外流浮水印：前台自動套用登入者 Email 滿版浮水印，強烈心理嚇阻。

前後台 1:1 富文本與版面最佳化

深度客製 TinyMCE 核心引擎與前端 DOM 重塑過濾器，實現 Word / Excel 貼上零誤差 1:1 高密度排版。

  • 1:1 零誤差盒模型：統一前後台表格邊距、儲存格內距與緊湊行距，消除視覺落差。
  • 智慧空行與雜訊淨化：遞迴剝離 Word/Excel 剪貼簿幽靈空白與冗餘標籤。
  • 商務專屬工具：內建 32 色蜂巢／莫蘭迪色盤、一鍵跨欄置中與自由拖拉欄寬。

週報點閱績效統計與數據匯出

前後台整合的視覺化 KPI 看板，自動追蹤各營運處閱讀狀況，並完整記錄點閱時間明細與 SheetJS Excel 報表匯出。

  • 自動結算與時間明細：自動彙算主要窗口閱讀率，完整呈現 YYYY/MM/DD HH:mm 打卡時間。
  • 防呆機制：自動排除工程處與未設主要窗口單位，確保營運 KPI 數據精準。
  • 公開透明：前台登入自動彈出統計看板，促進跨區團隊閱讀積極度。

一鍵打卡閉環與尊榮完讀金徽章

打破傳統「點開即算已讀」的粗糙統計，週報底部與浮動閱讀工具列均配置一鍵打卡通道，並採雲端非同步與 Token 自動刷新防護。

  • 雲端驗證打卡：點擊顯示 Loading 動畫並自動刷新 Token，Firestore 寫入成功方鎖定狀態。
  • 尊榮金徽章回饋：打卡成功即於 Header 點亮專屬「👑 已完讀」琥珀金徽章。
  • 完讀滿條常駐：已完讀同仁重開時常駐 100% 滿條，兼顧視覺標示與榮譽感。

多層次已讀容錯與後台手動補登

全面解決同仁因集團跨網域信箱、英文暱稱或同音異字導致無法比對中文姓名之痛點，並提供管理員自主補登介面。

  • 多維度容錯匹配：信箱、跨網域前綴、全半形去空格姓名與同音字交叉校驗。
  • 後台手動補登 Modal：管理員可直接挑選未讀同仁快速補登，即時連動雲端與 KPI。
  • 身分即時顯性化：前台 Header 呈現登入姓名與單位，後台名冊透明列出登入 Email。

全員防舞弊操作紀錄日誌 (Audit Log)

為杜絕舞弊並自證清白，所有在後台管理員清單中的成員執行任何關鍵操作，均受不可竄改日誌嚴格記錄。

  • 全員責任制入帳：發布週報、撤回發布、手動補登同仁已讀等重大行為全數留痕。
  • 實名中文解析：日誌動態解析操作者中文實名與信箱，告別英文暱稱與靜態寫死。
  • 測試帳號智慧排除：自動過濾技術人員測試操作，保障稽核軌跡真實純淨。

經典雙欄吸頂流與大字體清晰版型

採用「方案 A 固定置左吸頂歸檔目錄」，讓長篇週報捲動時左側檢索與歷史清單常駐隨行，並兼顧資深同仁閱讀舒適度。

  • 桌面側欄 Sticky 吸頂：捲動長文不中斷切期與搜尋，整合月份與類別即時篩選。
  • 等寬視覺對齊：主要佈告欄卡片、聯絡資訊與保密聲明完全等寬對齊。
  • 單期直達分享與骨架屏：支援 ?id= 連結分享與 Skeleton 載入過渡。

前台即時畫面預覽與多裝置模擬

徹底告別「發布後才發現排版瑕疵」的困擾，後台直接調用安全沙盒與 session 隔離層呈現 1:1 前台實景。

  • 零發布即時顯影：即時同步富文本與表格樣式，無須發布即可查閱完整排版。
  • 三合一多裝置視角：內建電腦全螢幕、平板 (768px)、手機 (414px) 響應式模擬。
  • 全隔離安全沙盒：預覽資料不寫入正式資料庫，前台線上讀者不受任何干擾。

主要聯絡人動態對齊與百分百完讀閉環

徹底解決組織調整與績效統計脫鉤難題，將各營運處在地責任體系與閱讀打卡邏輯嚴格閉環。

  • 工程處解耦與動態關聯：排除工程處，與通訊錄 isPrimary 保持 100% 動態同步。
  • 已打卡即 100% 完讀真理：同仁打卡確認後閱讀進度無條件視為滿分，根除均分 70% 瑕疵。
  • 歷史進度全自動補正：具備自癒校驗引擎，一鍵修復過往存根，呈現精確無瑕的營運績效。

雙通道需求問卷與填答進度互動

打破單向公告藩籬，前台雙通道銜接專屬 3D 黏土風問卷系統，提供即時進度追蹤、缺漏提示與全集團身分驗證。

  • 吸頂進度條與即時驗證：顯示「必填 X / 5 項」進度條，缺漏欄位自動捲動搖晃並彈出 Toast。

零信任多網域防禦與憑證無縫自癒

將資安提升至雲端伺服器級別，同時兼顧跨集團子公司同仁的順暢登入與無感續期體驗。

  • 全集團規則不區分大小寫：Firestore Rules 以 (?i) 校驗 isCompanyUser()，相容大小寫與集團多網域。
  • 全集合禁止物理刪除：強制 allow delete: if false;，徹底免除誤刪或惡意洗庫風險。
  • 打卡憑證無縫自癒：內建 trySeamlessReAuth 與 Token 自動刷新，根除過期權限錯誤。

關鍵字螢光高亮檢索與懸浮導覽

打造純 DOM 文字節點層級的即時高亮引擎，輸入料號、廠商或關鍵字時零破壞表格結構，一鍵定位所有命中段落。

  • 精準螢光與整列標亮：支援多關鍵字空格搜尋，mark.search-hl 螢光標示並柔光提示整列表格。
  • 懸浮跳轉列與快捷鍵：提供「第 X / N 筆」上下跳轉條，支援 Enter / Shift+Enter / Esc。
  • 命中徽章與跨月份引導：側欄顯示各期命中次數，當月無結果時自動提示切換「全部月份」。

行動智慧表格排版與全方位閱讀輔助

專為採購長表與手機閱讀痛點打造的智慧排版引擎，並整合粉紅醒目附件區、燈箱、字級縮放與純淨 PDF 列印。

  • 手機智慧防斷行與全螢幕放大：自動解除 Word 殘留欄寬、保護料號／日期不斷行，支援一鍵全螢幕檢視與凍結表頭。
  • 粉紅高辨識附件專區：段落標頭附帶快跳膠囊，鮮明粉紅卡片與類型徽章徹底避免同仁漏看附件。
  • 完整閱讀工具組：章節快跳目錄、圖片點擊放大燈箱、A-/100%/A+ 字級縮放與 @media print 純淨列印。

後台高效率中台與三大設定引擎

為採購編輯團隊量身打造的高生產力作業中台，串聯動態首頁儀表板、防誤觸保護、催讀工作流與三大設定工作台。

  • 高效編輯與防誤觸：動態首頁 4 卡統計、Ctrl+S 快捷存檔與未儲存徽章、段落一鍵收合與頂部 ⋯ 更多 危險操作隔離。
  • 一鍵催讀工作流：已讀追蹤支援「全部／已讀／未讀／主要窗口」篩選，並可一鍵複製未讀 Email 催讀。
  • 三大設定工作台：通訊錄 Excel 匯出入、發信群組幽靈信箱自癒 (sanitizeAllGroupEmails) 與 9 大構面拖曳詞庫。
