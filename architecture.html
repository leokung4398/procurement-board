專案核心亮點與技術邏輯

Serverless 無伺服器架構

捨棄傳統需要買主機、架設作業系統的框架。全站採用 HTML5 + JS 開發，搭配 GitHub Actions 實現 CI/CD，每次修改程式碼就會自動發佈至 GitHub Pages。

  • 維護成本為零，無須擔心主機當機
  • 全球 CDN 加速，開啟網頁瞬間完成
  • 架構極輕量，移交與接手門檻低

Firebase 企業級資料雲

後端資料庫選用 Google 的 Firebase Firestore (NoSQL)，具備極高的擴充性。圖文附件則上傳至 Cloud Storage。

  • 資安防護：透過 Security Rules 嚴格阻擋非管理員的惡意竄改。
  • 稽核軌跡：後台具備 Audit Logs (操作紀錄)，誰在什麼時候發布皆有跡可循。
  • 即時同步更新，資料落地安全有保障。

EmailJS 自動化通知引擎

過去寄發週報需要人工一封封複製貼上，現在系統內建聯絡人與群組管理，並直接串接 EmailJS API。

  • 後台點擊「發布」，自動抓取必讀重點。
  • 動態生成 HTML 豐富排版（包含圖片）寄送給同仁。
  • 徹底消除人工發信的人為疏失與時間成本。

全域權限與強制更新

系統具備 Global Whitelist (全域白名單) 權限控管與 Version Checker (強制更新) 機制。

  • 通訊錄名單即為全站觀看權限，無須逐篇設定
  • 管理員可透過 ?test_user=1 模擬前台權限
  • 發布新版時透過比對 version.txt 強制破除瀏覽器暫存

機密週報防護機制

針對特定高敏資料引入了 ACL (存取控制清單) 機制。發布時動態解析收件群組，並在資料庫底層嚴格管制讀取權限。

  • 資料庫閘門：Firebase Security Rules 從底層攔截越權存取。
  • 動態群組展開：發布時將群組解碼為個人 Email 名單供權限比對。
  • 防外流浮水印：前台自動套用登入者 Email 滿版浮水印，強烈心理嚇阻。

前端版面極致最佳化

為迎合使用者對於「高密度資訊、無留白」的嚴格要求，在前端實作了深度的 HTML 過濾與 DOM 重塑引擎。

  • 智慧空行消除：遞迴剝離富文本編輯器產生的幽靈空白與換行。
  • 響應式懸浮微標：「緊急」標籤改為 Hover 觸發，不佔用任何版面空間。
  • 強制版面壓縮：覆寫 Tailwind 與 Quill 預設樣式，實現 0 padding/margin。
