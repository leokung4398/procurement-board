專案核心亮點與技術邏輯

Serverless 無伺服器架構

捨棄傳統需要買主機、架設作業系統的框架。全站採用 HTML5 + JS 開發，搭配 GitHub Actions 實現 CI/CD，每次修改程式碼就會自動發佈至 GitHub Pages。

  • 維護成本為零，無須擔心主機當機
  • 全球 CDN 加速，開啟網頁瞬間完成
  • 架構極輕量，移交與接手門檻低

Firebase 企業級資料雲

後端資料庫選用 Google 的 Firebase Firestore (NoSQL)，具備極高的擴充性。圖文附件則上傳至 Cloud Storage。

  • 資安防護：透過 Security Rules 嚴格阻擋非管理員的惡意竄改。
  • 稽核軌跡：後台具備 Audit Logs (操作紀錄)，誰在什麼時候發布皆有跡可循。
  • 即時同步更新，資料落地安全有保障。

EmailJS 自動化通知引擎

過去寄發週報需要人工一封封複製貼上，現在系統內建聯絡人與群組管理，並直接串接 EmailJS API。

  • 後台點擊「發布」，自動抓取必讀重點。
  • 動態生成 HTML 豐富排版（包含圖片）寄送給同仁。
  • 徹底消除人工發信的人為疏失與時間成本。

全域權限與強制更新

系統具備 Global Whitelist (全域白名單) 權限控管與 Version Checker (強制更新) 機制。

  • 通訊錄名單即為全站觀看權限，無須逐篇設定
  • 管理員可透過 ?test_user=1 模擬前台權限
  • 發布新版時透過比對 version.txt 強制破除瀏覽器暫存

機密週報防護與選擇性隱藏

針對高敏或特定廠區週報引入 ACL 存取控制 與 選擇性隱藏開關。後台勾選特定人員或隱藏後，前台即刻隔離。

  • 精準存取過濾：非授權同仁清單完全不顯示，網址直接開啟亦安全鎖定。
  • 選擇性隱藏開關：校對中或特定檔期一鍵隱藏，毋須刪除歷史文檔。
  • 防外流浮水印：前台自動套用登入者 Email 滿版浮水印，強烈心理嚇阻。

前端版面極致最佳化

為迎合使用者對於「高密度資訊、無留白」的嚴格要求，在前端實作了深度的 HTML 過濾與 DOM 重塑引擎。

  • 智慧空行消除：遞迴剝離富文本編輯器產生的幽靈空白與換行。
  • 響應式懸浮微標：「緊急」標籤改為 Hover 觸發，不佔用任何版面空間。
  • 強制版面壓縮：覆寫 Tailwind 與 Quill 預設樣式，實現 0 padding/margin。

週報點閱績效統計與數據匯出

前後台整合的視覺化 KPI 看板，能自動追蹤各營運處的閱讀狀況，並支援 Excel 報表匯出。

  • 自動結算：自動計算主要聯絡人的應讀與已讀數據。
  • 防呆機制：防呆過濾未設定主要聯絡人的單位，避免數據失真。
  • 公開透明：前台登入自動彈出統計看板，促進團隊內部閱讀積極度。

一鍵打卡閉環與尊榮完讀金徽章

打破傳統「點開即算已讀」的粗糙統計，週報底部配置商務微漸層打卡按鈕，並採雲端非同步防護。

  • 底端一鍵打卡：點擊顯示 Loading 旋轉動畫，Firestore 驗證寫入成功方鎖定狀態。
  • 尊榮金徽章回饋：打卡成功即於 Header 點亮專屬「👑 已完讀」琥珀金徽章。
  • 完讀滿條常駐：已完讀同仁重開時常駐 100% 滿條，兼顧視覺標示與榮譽感。

多層次已讀容錯與後台手動補登

全面解決同仁因 Google 英文暱稱或同音異字導致無法比對中文姓名之痛點，並提供管理員自主補登介面。

  • 多維度容錯匹配：信箱、前綴、全半形去空格姓名與同音字交叉校驗。
  • 後台手動補登 Modal：管理員可直接挑選未讀同仁快速補登，即時連動雲端與 KPI。
  • 身分即時顯性化：前台 Header 呈現登入姓名與單位，後台名冊透明列出登入 Email。

全員防舞弊操作紀錄日誌 (Audit Log)

為杜絕舞弊並自證清白，所有在後台管理員清單中的成員執行任何關鍵操作，均受不可竄改日誌嚴格記錄。

  • 全員責任制入帳：發布週報、撤回發布、手動補登同仁已讀等重大行為全數留痕。
  • 實名中文解析：日誌動態解析操作者中文實名與信箱，告別英文暱稱與靜態寫死。
  • 測試帳號智慧排除：自動過濾技術人員測試操作，保障稽核軌跡真實純淨。

經典雙欄流與大字體清晰版型

採用使用者最直觀的「方案 A 固定置左歸檔目錄」，並為資深同仁專屬升級大字體與同寬版型架構。

  • 歷史歸檔靠左整合：整合關鍵字即時檢索、月份與類別篩選，大字體觸控好點選。
  • 等寬視覺對齊：中間主要佈告欄內容卡片與下方頁尾聯絡資訊／保密聲明完全等寬。
  • 高適配無收合障礙：移除不穩定的側邊收合按鈕，跨不同解析度維持最高一致性。

前台即時畫面預覽與多裝置模擬

徹底告別「發布後才發現排版瑕疵」的困擾，後台直接調用安全沙盒與 session 隔離層呈現 1:1 前台實景。

  • 零發布即時顯影：即時同步富文本與表格樣式，無須發布即可查閱完整排版。
  • 三合一多裝置視角：內建電腦全螢幕、平板 (768px)、手機 (414px) 響應式模擬。
  • 全隔離安全沙盒：預覽資料不寫入正式資料庫，前台線上讀者不受任何干擾。
