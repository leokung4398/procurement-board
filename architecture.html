系統全貌與 IT 技術規格白皮書 (Solution C: IT 專用結構化全景)

採購佈告欄系統架構與全鏈路運作邏輯

本專案採用 前後端解耦之 Serverless（無伺服器）企業架構。前端託管於 GitHub Pages 搭配全球 CDN；後端全面託管於 Google Firebase (Firestore + Storage + Auth)；通知層直連 EmailJS API。全站具備零實體主機維護負擔、零資料庫停機風險、高強度資安防護與全自動化 CI/CD。

部署機制 GitHub Actions CI/CD
資安管控 OAuth + Security Rules

1 系統全鏈路資料流向與分層拓撲 (Architecture Layers)

直覺清晰 · 橫跨使用者、安全閥、前後端至雲端整合
Layer 1 👥

終端使用者與安全門禁

區分「一般同仁 (Reader)」與「採購管理員 (Admin)」，強制經過企業認證牆。

🔐 Google OAuth 企業網域門禁 強制鎖定 @youbike.com.tw 網域登入，外來帳號直接阻斷。
👁️ ACL 存取過濾引擎 前台載入時自動交叉比對機密週報白名單與隱藏旗標，未獲授權無從讀取。
流向 ➔ 前端介面層 Security First
Layer 2 🌐

前端介面層 (SPA Client)

以純原生 HTML5 / CSS3 / ES6+ 開發，託管於 GitHub Pages CDN 零延遲發布。

前台 (index.html) 經典雙欄檢索流、即時關鍵字查詢、一鍵完讀漸層打卡、Email 浮水印與高斯防窺。
後台 (admin.html) TinyMCE 富文本淨化編輯、多裝置模擬預覽、選擇性隱藏開關、Audit Logs 防舞弊日誌。
流向 ➔ Firebase BaaS Zero Server Load
Layer 3 ☁️

雲端後端 BaaS (Firebase)

提供高可用性、自動彈性擴展之 NoSQL 資料庫與企業級雲端儲存空間。

🛡️ Security Rules 防護牆 資料庫層級細緻權限：只允許驗證之管理員寫入，同仁僅限唯讀與個人打卡。
📦 Firestore & Cloud Storage 管理週報(bulletins)、打卡(readReceipts)、名冊(systemConfig)、稽核(auditLogs)與附件檔案。
流向 ➔ 外部整合服務 Auto Scaling
Layer 4 ⚙️

自動化與 CI/CD 引擎

整合自動推播 API 與 Git 原始碼版本控管，實現代碼即服務的現代工程。

✉️ EmailJS API 自動推播 發布時自動提取「緊急」必讀項目，動態組合富文本 HTML 郵件發送至同仁信箱。
🚀 GitHub Actions CI/CD 代碼推送 GitHub 自動觸發編譯部署；配合 version.txt 實現客戶端強制破除快取。

2 業務核心資料流與防呆時序 (Key Process Workflows)

清晰步驟化呈現前後端資料流
A

企業身分鑑別與權限過濾流

  1. 01 Google 登入請求：同仁透過 Firebase Client SDK 觸發 Google Sign-In 彈窗。
  2. 02 網域校驗門禁：前端立即檢查 Email 是否以 @youbike.com.tw 結尾，非企業信箱立刻登出。
  3. 03 白名單比對與實名快取：比對 systemConfig/whitelist，取得使用者所屬單位與中文實名。
  4. 04 ACL 機密過濾：查詢 Firestore 週報時，過濾掉已隱藏者，且機密週報僅有在名單內的 Email 才會接收到文檔。
B

週報發布與 Email 自動推播流

  1. 01 後台富文本編撰：透過 TinyMCE 與 Excel 淨化過濾器輸入採購內容，自動消除格式雜訊與幽靈空白。
  2. 02 三合一沙盒預覽：管理員切換電腦/平板/手機視角確認 1:1 實景排版，資料不落正式庫。
  3. 03 Firestore 原子寫入：狀態更新為 published，並自動寫入一筆全員防舞弊 Audit Log 記錄發布者實名。
  4. 04 EmailJS 批次發送：後台調用 EmailJS 服務，將本週重點與緊急公告帶圖片直接發送至同仁公務信箱。
C

完讀打卡閉環與點閱績效統計流

  1. 01 同仁滑動閱讀打卡：讀完全文後點擊底部「已詳細閱讀並知悉」，按鈕立即呈現旋轉載入防重複點擊。
  2. 02 寫入已讀存根與 100% 完讀真理：Firestore 集合 readReceipts 寫入包含週報 ID、同仁信箱、精確時間戳記與 confirmed: true（打卡確認即 100% 完讀）。
  3. 03 前端金徽章鎖定：成功打卡後頂端立即亮起「👑 已完讀」琥珀金徽章，再次進入時常駐 100% 滿條。
  4. 04 KPI 即時彙算與動態對齊：後台讀取打卡記錄與通訊錄，動態對齊最新主要負責人名冊並排除工程處，自動彙算各縣市 100% 完讀率與 SheetJS 報表導出。

3 專案核心亮點與深度技術架構 (Technical Highlights · 16 大核心構面)

全方位滿足企業級系統之維護與資安標準

Serverless 無伺服器架構

捨棄傳統需要買主機、架設作業系統的框架。全站採用 HTML5 + JS 開發，搭配 GitHub Actions 實現 CI/CD，每次修改程式碼就會自動發佈至 GitHub Pages。

  • 維護成本為零，無須擔心實體主機硬體當機
  • 全球 CDN 加速，開啟網頁瞬間完成零延遲
  • 架構極輕量，移交與接手門檻低

Firebase 企業級資料雲

後端資料庫選用 Google 的 Firebase Firestore (NoSQL)，具備極高的擴充性。圖文附件則上傳至 Cloud Storage。

  • 資安防護：透過 Security Rules 嚴格阻擋非管理員的惡意竄改。
  • 稽核軌跡：後台具備 Audit Logs (操作紀錄)，誰在什麼時候發布皆有跡可循。
  • 即時同步更新，資料落地安全有保障。

EmailJS 自動化通知引擎

過去寄發週報需要人工一封封複製貼上，現在系統內建聯絡人與群組管理，並直接串接 EmailJS API。

  • 後台點擊「發布」，自動抓取必讀重點。
  • 動態生成 HTML 豐富排版（包含圖片）寄送給同仁。
  • 徹底消除人工發信的人為疏失與時間成本。

全域權限與強制更新

系統具備 Global Whitelist (全域白名單) 權限控管與 Version Checker (強制更新) 機制。

  • 通訊錄名單即為全站觀看權限，無須逐篇設定
  • 管理員可透過 ?test_user=1 模擬前台權限
  • 發布新版時透過比對 version.txt 強制破除瀏覽器暫存

機密週報防護與選擇性隱藏

針對高敏或特定廠區週報引入 ACL 存取控制 與 選擇性隱藏開關。後台勾選特定人員或隱藏後，前台即刻隔離。

  • 精準存取過濾：非授權同仁清單完全不顯示，網址直接開啟亦安全鎖定。
  • 選擇性隱藏開關：校對中或特定檔期一鍵隱藏，毋須刪除歷史文檔。
  • 防外流浮水印：前台自動套用登入者 Email 滿版浮水印，強烈心理嚇阻。

前端版面極致最佳化

為迎合使用者對於「高密度資訊、無留白」的嚴格要求，在前端實作了深度的 HTML 過濾與 DOM 重塑引擎。

  • 智慧空行消除：遞迴剝離富文本編輯器產生的幽靈空白與換行。
  • 響應式懸浮微標：「緊急」標籤改為 Hover 觸發，不佔用任何版面空間。
  • 強制版面壓縮：覆寫 Tailwind 與 Quill 預設樣式，實現 0 padding/margin。

週報點閱績效統計與數據匯出

前後台整合的視覺化 KPI 看板，能自動追蹤各營運處的閱讀狀況，並支援 Excel 報表匯出。

  • 自動結算：自動計算主要聯絡人的應讀與已讀數據。
  • 防呆機制：防呆過濾未設定主要聯絡人的單位，避免數據失真。
  • 公開透明：前台登入自動彈出統計看板，促進團隊內部閱讀積極度。

一鍵打卡閉環與尊榮完讀金徽章

打破傳統「點開即算已讀」的粗糙統計，週報底部配置商務微漸層打卡按鈕，並採雲端非同步防護。

  • 底端一鍵打卡：點擊顯示 Loading 旋轉動畫，Firestore 驗證寫入成功方鎖定狀態。
  • 尊榮金徽章回饋：打卡成功即於 Header 點亮專屬「👑 已完讀」琥珀金徽章。
  • 完讀滿條常駐：已完讀同仁重開時常駐 100% 滿條，兼顧視覺標示與榮譽感。

多層次已讀容錯與後台手動補登

全面解決同仁因 Google 英文暱稱或同音異字導致無法比對中文姓名之痛點，並提供管理員自主補登介面。

  • 多維度容錯匹配：信箱、前綴、全半形去空格姓名與同音字交叉校驗。
  • 後台手動補登 Modal：管理員可直接挑選未讀同仁快速補登，即時連動雲端與 KPI。
  • 身分即時顯性化：前台 Header 呈現登入姓名與單位，後台名冊透明列出登入 Email。

全員防舞弊操作紀錄日誌 (Audit Log)

為杜絕舞弊並自證清白，所有在後台管理員清單中的成員執行任何關鍵操作，均受不可竄改日誌嚴格記錄。

  • 全員責任制入帳：發布週報、撤回發布、手動補登同仁已讀等重大行為全數留痕。
  • 實名中文解析：日誌動態解析操作者中文實名與信箱，告別英文暱稱與靜態寫死。
  • 測試帳號智慧排除：自動過濾技術人員測試操作，保障稽核軌跡真實純淨。

經典雙欄流與大字體清晰版型

採用使用者最直觀的「方案 A 固定置左歸檔目錄」，並為資深同仁專屬升級大字體與同寬版型架構。

  • 歷史歸檔靠左整合：整合關鍵字即時檢索、月份與類別篩選，大字體觸控好點選。
  • 等寬視覺對齊：中間主要佈告欄內容卡片與下方頁尾聯絡資訊／保密聲明完全等寬。
  • 高適配無收合障礙：移除不穩定的側邊收合按鈕，跨不同解析度維持最高一致性。

前台即時畫面預覽與多裝置模擬

徹底告別「發布後才發現排版瑕疵」的困擾，後台直接調用安全沙盒與 session 隔離層呈現 1:1 前台實景。

  • 零發布即時顯影：即時同步富文本與表格樣式，無須發布即可查閱完整排版。
  • 三合一多裝置視角：內建電腦全螢幕、平板 (768px)、手機 (414px) 響應式模擬。
  • 全隔離安全沙盒：預覽資料不寫入正式資料庫，前台線上讀者不受任何干擾。

主要聯絡人動態對齊與百分百完讀閉環

徹底解決組織調整與績效統計脫鉤難題，將各營運處在地責任體系與閱讀打卡邏輯嚴格閉環。

  • 工程處解耦與動態關聯：排除工程處，與通訊錄 isPrimary 保持 100% 動態同步。

雲端零信任伺服器安全與防物理刪除

告別前端假性防護，將資安提升至雲端伺服器級別，打造無法被 F12 或惡意外部腳本穿透的防護鐵幕。
